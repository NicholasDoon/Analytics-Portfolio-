# Analytics Portfolio

This portfolio contains applied data analytics projects using SQL, Python, Excel, and statistical analysis.

## Projects

### 1. Online Retail CRM Segmentation
Analyzed 500,000+ retail transactions using SQL and Python to segment customers with RFM analysis.

Tools: SQL, Python, pandas, matplotlib

[View Project](https://github.com/NicholasDoon/online-retail-crm-segmentation)

### 2. Insurance Customer Analysis
Used SQL to analyze insurance customer behavior, claim amounts, sales channels, customer lifetime value, and renewal offer effectiveness.

Tools: SQL, SQLite

[View Project](https://github.com/NicholasDoon/insurance-customer-analysis)

---

### 3. British Airways Lounge Eligibility Model
Built a predictive model to classify lounge eligibility and evaluate performance using recall, precision, and ROC-AUC.

Tools: Python, scikit-learn, pandas
[View Project](https://github.com/NicholasDoon/Analytics-Portfolio-/tree/main/british-airways-lounge-eligibility)
